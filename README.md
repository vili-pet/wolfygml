# GLM Key Telemetry Dashboard

A lightweight telemetry and monitoring dashboard for GLM-5.3-Flash (Z.AI) API keys managed through a LiteLLM proxy. It provides real-time token tracking, session statistics, rate-limit visibility, and latency monitoring, designed to run on a Raspberry Pi.

The project exists to make proxy-key usage and service health visible at a glance on a small, self-hosted device.
